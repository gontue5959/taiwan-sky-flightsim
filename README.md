# 台灣天空 飛行模擬器（Windows 版）

這個專案只放打包好的安裝檔，原始碼不在這裡。

## 下載

到 [Releases](../../releases/latest) 下載最新版：

- **TaiwanSkyFlightSim-Setup-x.y.z.exe**：安裝版，**會自動更新**（建議）
- **TaiwanSkyFlightSim-Portable-x.y.z.exe**：免安裝版，可放隨身碟；有新版時會提示，但要手動下載

系統需求：Windows 10／11 64 位元。第一次開啟時若出現「Windows 已保護您的電腦」（程式沒有數位簽章），按「其他資訊」→「仍要執行」。

## 自動更新

安裝版每次啟動會檢查這裡有沒有新版，有的話會詢問是否下載；下載完成後可立即重新啟動安裝，或等下次關閉程式時自動安裝。不需要帳號，也不會上傳任何資料。
